# SporeNet

> Экожүйені қалпына келтіретін жол — The path to restoring ecosystems

Project website for **SporeNet**, an eco-project restoring underground mycorrhizal networks in Kazakhstan's burned forests. Submitted to **Turaqty Jol 7.0** (UNESCO Clubs Federation of Kazakhstan).

## Stack

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** with custom natural palette (moss + ochre)
- **next-intl** — i18n for English / Русский / Қазақша
- **next-themes** — light / dark mode
- **Framer Motion**, **react-countup** — interactive elements

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

This repo is configured to deploy on **Vercel** — connect the repo and it will build automatically.
